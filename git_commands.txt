COMMAND LOG: Greenleaf Community Garden repository
===================================================
Every command I typed for this assignment, numbered in the order I ran it.
Layout:  [no.] command
              purpose of the command

[01] mkdir community-garden-site
         Make an empty folder that will hold the website.

[02] cd community-garden-site
         Step inside it so the remaining commands act on this project.

[03] ls
         Check that index.html and about.html are present before tracking them.

[04] git init -b main
         Start version control here; the default branch is called main.

[05] git status --short
         Quick view of the working tree. "??" means a file Git does not track yet.

[06] git add index.html about.html
         Put both pages in the staging area for the first snapshot.

[07] git commit -m "Add homepage and about page for the garden club site"
         Save the staged pages as the initial commit.

[08] git commit -am "Add upcoming events section to homepage"
         After editing index.html, stage the tracked change and commit it in one command (second commit).

[09] git branch feature
         Create a branch named feature at the current commit.

[10] git switch feature
         Move onto that branch so my next commit lands there instead of on main.

[11] git add about.html
         Stage the about page, which now lists the volunteer team.

[12] git commit -m "Add volunteer team section to about page"
         Record the change; only the feature branch moves forward.

[13] git switch main
         Go back to main, which does not yet contain the volunteer list.

[14] git merge --no-ff feature -m "Merge feature: volunteer team section"
         Bring the feature work into main. --no-ff always creates a merge commit, so the branch stays visible.

[15] git log --graph --oneline --decorate --all
         Draw the full history as an ASCII graph, one line per commit, with branch labels.

[16] cat .gitignore
         Print the ignore file to show its two rules: *.log and temp/.

[17] git status --short --ignored
         Same short status, but also lists ignored items with the "!!" prefix.

[18] git check-ignore -v debug.log temp/scratch.txt
         Ask Git which rule (file and line) is hiding each of the two test files.

[19] git add .gitignore
         Stage the new ignore file.

[20] git commit -m "Add .gitignore for log files and temp folder"
         Commit the ignore rules.

[21] git commit -am "Add experimental seed-sale banner"
         Make one more commit, the one I will undo.

[22] git log --oneline -3     (and later)     git log --oneline -4
         Show the newest 3 or 4 commits in one-line form, before and after the undo.

[23] git revert --no-edit HEAD
         Undo the last commit by adding a new commit that cancels it out; old history is not rewritten.

[24] git diff --stat HEAD~2 HEAD
         Compare the project before the banner with now. No output means the files are the same.

[25] git show --stat --format="%h %s" HEAD
         Display the revert commit and which file/line count it changed.

[26] grep -c "SEED SALE" index.html
         Count lines that still contain the banner text; 0 means it is gone.

[27] git add git_commands.txt
         Stage this documentation file.

[28] git commit -m "Add git_commands.txt documenting every command used"
         Commit it with the rest of the project.

[29] gh repo create community-garden-git-assignment --public
         GitHub CLI: create a new, empty public repository on my GitHub account.

[30] git remote add origin https://github.com/Raghavendra1729-cell/community-garden-git-assignment.git
         Register that repository as the remote named origin.

[31] git remote -v
         List the remotes and their fetch/push URLs to confirm the link.

[32] git push -u origin main
         Upload main to GitHub and remember origin/main as its upstream branch.

[33] git push origin feature
         Upload the feature branch too, so the branch is visible online.

[34] gh repo view Raghavendra1729-cell/community-garden-git-assignment --json visibility,url
         Ask GitHub for the repo's visibility and URL (expected: PUBLIC).

[35] git branch -a
         List local and remote-tracking branches to check both reached GitHub.

[36] git commit -am "Fix git show entry in git_commands.txt"
         Small correction to this file after I noticed one command was written differently from what I ran.

[37] git push origin main
         Send that correction to GitHub.

[38] git commit -am "Rewrite git_commands.txt as a numbered command log"
         Final tidy-up of this file into the numbered format you are reading.

[39] git status
         Confirm the working tree is clean and main matches origin/main.
